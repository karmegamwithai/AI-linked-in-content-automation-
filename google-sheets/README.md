# Google Sheets Integration Guide

This directory contains specifications and schemas for using Google Sheets as a headless CMS and content calendar for the ContentFlow automation pipeline.

## Structure
- `/schema/posts.md` - Post content, formats, media links, and draft statuses.
- `/schema/schedules.md` - Timing and recurrent cadence rules.
- `/schema/analytics.md` - Automated sync-back schema for post metrics.
- `/schema/users.md` - Team member attribution and approval workflows.
