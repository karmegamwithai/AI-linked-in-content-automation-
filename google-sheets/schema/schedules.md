# Google Sheets Schedules Schema

| Column | Field Name | Type | Description |
|---|---|---|---|
| A | Schedule_ID | String | Schedule rule identifier |
| B | Day_Of_Week | String | \`MON\`, \`TUE\`, \`WED\`, etc. |
| C | Time_UTC | Time | \`14:00\` |
| D | Target_Platform | Enum | \`LINKEDIN\` \| \`INSTAGRAM\` \| \`BOTH\` |
| E | Active | Boolean | \`TRUE\` / \`FALSE\` |
