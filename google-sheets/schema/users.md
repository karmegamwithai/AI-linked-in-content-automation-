# Google Sheets Users Schema

| Column | Field Name | Type | Description |
|---|---|---|---|
| A | User_ID | String | Unique user ID |
| B | Name | String | Author full name |
| C | Email | String | Notification email |
| D | Role | Enum | \`ADMIN\` \| \`CREATOR\` \| \`REVIEWER\` |
| E | Default_Timezone | String | e.g. \`America/Los_Angeles\` |
